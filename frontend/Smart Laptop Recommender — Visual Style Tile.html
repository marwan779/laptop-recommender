Visual Style Tile · Companion to DESIGN.md

The Verified Instrument identity, rendered in its own tokens

Smart Laptop Recommender turns live Egyptian retailer prices, Icecat lab specs, TOPSIS multi-criteria ranking and real-world review intelligence into trustworthy picks for a volatile market. The visual system behaves like a precision instrument on a lab bench: dark, quiet surfaces so the data carries the page, Cairo gold only where money and decisions live, cyan for everything quantitative, and muted indigo reserved for the thinking parts — TOPSIS, NLP and AI. Every specimen below is built from the exact tokens in DESIGN.md, with copy, prices and scores taken from the live application.

Gold = money & decisionsPrimary actions, TOPSIS match %, prices, selected states. One gold focal point per card.
Cyan = dataEvery score bar, benchmark and spec value. Cyan never appears on a button.
Indigo = intelligenceTOPSIS / NLP / AI labels only. Never a price, never a primary action.
Green & red = judgementVerified vs unverified, pros vs cons. Amber is caution only — never a neutral fact.

Buttons, chips & controls

Data is flat, actions are solid. Each card has exactly one gold focal point.

Buttons

Primary — gold fill, dark label, 44px. Secondary — outline, gold on hover. Ghost — borderless, for toggles like “Collapse”. Disabled shown at 40% opacity. Labels copied from the live UI.
